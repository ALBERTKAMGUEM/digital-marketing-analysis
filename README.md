# Analyse des performances du marketing digital

## Présentation du projet

Ce projet de Data Analytics analyse la stratégie de marketing digital de **Shapr**, à partir de données publicitaires issues de Facebook et Instagram.

L'objectif est d'explorer les données, de préparer les informations nécessaires à l'analyse et d'étudier les dépenses marketing sur les réseaux sociaux.

## Objectifs

- Explorer et analyser les données publicitaires.
- Nettoyer et préparer les données avec Pandas.
- Étudier les dépenses publicitaires sur Facebook et Instagram.
- Analyser la répartition des investissements par canal.
- Comparer les dépenses marketing et identifier les tendances.

## Technologies utilisées

- **Python**
- **Pandas**
- **Jupyter Notebook**
- **Analyse exploratoire de données**
- **Nettoyage et préparation des données**
